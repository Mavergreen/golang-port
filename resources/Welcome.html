This installs a modern Go @GO_MINOR@ toolchain, patched to build and run on Mac OS X 10.9 (Mavericks), into /usr/local/mavergreen/go@GO_LINE@/.

Open a new Terminal window: go and go-@GO_LINE@ are on your PATH, and go build works out of the box — cgo included — producing 10.9-safe binaries with modern TLS (verified against the system keychain plus a bundled CA set).

Every go build for 10.9 links with clang22, pure-Go programs too. Install clang22 first (from Mavergreen's clang-22 releases, or with Longboat; the cross toolchain wants clang22-cross); this installer checks for it. You do not need the Command Line Tools.

A background updater (Sparkle) checks daily for new releases. Built from go.dev source; no Apple prebuilt toolchain is redistributed.
